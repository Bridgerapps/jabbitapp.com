What to track (high-signal, low-effort)

Most “is it working?” or “is this a side effect?” questions become easier when you can see a simple timeline.

1) Your schedule (the anchor)

Day Time Action Notes
Mon / Tue / … ____ : ____ Injection / dose (as prescribed) Meals / sleep / travel / stress
Mon / Tue / … ____ : ____ Reminder / check-in How you felt / appetite / energy

2) Dose / injection log template

Date Time Dose Site Batch / notes Context
____ / ____ / ____ ____ : ____ As prescribed ____________ ____________ Sleep / meals / travel / stress
____ / ____ / ____ ____ : ____ As prescribed ____________ ____________ Sleep / meals / travel / stress

3) Side effects notes (timing beats memory)

If you only write down one thing: write down when it started relative to your last dose.

Time since dose Symptom Severity Trigger guess Notes
+ 6h / + 1d / + 3d ____________ 0–10 meal / sleep / stress ____________
+ 6h / + 1d / + 3d ____________ 0–10 meal / sleep / stress ____________
Shortcut: If you’re tracking a specific medication, use a drug-specific page (example: retatrutide tracker) and keep the same “schedule + dose + timeline” structure.

Use cases

  • Daily / EOD schedules
  • Multi-step titration routines
  • Inventory + timing (vials, open dates, remaining volume)
  • Site rotation patterns
