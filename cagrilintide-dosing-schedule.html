What this page is (and isn’t)

This is a logging template — not dosing guidance. It helps you keep a clean record of your weekly rhythm (planned vs actual), changes, and what happened afterward so you can review it with a licensed clinician.

Start with one “anchor”

  • Anchor day/time: pick the weekly slot you’re aiming for (ex: “Sunday night”).
  • Reality field: always record the actual date/time. Don’t rely on memory.
  • One-sentence note: “on time”, “late because travel”, “missed because supply”, etc.

What to log each week

  • Planned day (your intended weekly anchor)
  • Actual date + time (what happened)
  • Dose (as prescribed) and dose change notes
  • Reason for deviation (travel, side effects, supply, forgot, etc.)
  • Injection site (optional, but useful if you rotate)
