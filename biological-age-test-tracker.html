Biological Age Test Tracker: Epigenetic Clocks and Protocol Notes

Biological age tests are interesting trend signals, not magic truth machines. The useful part is logging test dates, methods, protocol changes, and context.

Track biological age tests and protocol context in Jabbit
Evidence boundary: Epigenetic clocks estimate aging-related signals. Clinical actionability is still limited, and one test change should not be treated as proof that a protocol works.

What to log

FieldWhy
Test name and dateDifferent clocks measure different things; keep method and lab together.
Result and unitsBiological age, pace score, percentile, confidence range if available.
Protocol changesGLP-1s, peptides, supplements, sleep, exercise, nutrition, alcohol, medications.
ContextIllness, travel, poor sleep, weight change, training load, stress.
Conventional labsA1c, ApoB/lipids, blood pressure, hs-CRP, liver/kidney markers if ordered.
